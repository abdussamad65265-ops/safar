# ShopSphere - E-commerce Product Catalog

**Developer:** Abdul Samad

## Overview
ShopSphere is a full-stack e-commerce product catalog web application built using React, Node.js, Express, and MongoDB. Users can browse products, filter by category, search by name, and view complete product details.

## Features
- Responsive UI
- Product listing
- Product details page
- Category filtering
- Search functionality
- RESTful API
- MongoDB database integration
- Deployment-ready architecture

## Tech Stack
- React
- Vite
- Node.js
- Express
- MongoDB
- CSS
