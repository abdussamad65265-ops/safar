# Personal Portfolio Website

This project is a simple multi-page personal portfolio website built using HTML5. The main focus of the project is to use semantic HTML structure and make the website accessible and easy to navigate.

## What I Built

* Created a multi-page personal portfolio website
* Used semantic HTML5 elements like `header`, `nav`, `main`, `section`, `article`, and `footer`
* Added proper headings and page structure
* Added accessible labels and ARIA attributes where required
* Created a keyboard-friendly contact form
* Added SEO-friendly meta information
* Kept the structure clean and easy to understand

## Accessibility

I tried to make the website usable for different users, including people who use keyboard navigation or screen readers. The pages follow basic WCAG accessibility practices and use meaningful HTML elements instead of relying only on generic `div` elements.

## Technologies Used

* HTML5
* CSS3
* Basic Accessibility / ARIA
* SEO Meta Tags

## How to Run

Download or clone this repository and open the `index.html` file in any modern web browser.

## Project Goal

The goal of this project was to understand how semantic HTML5 improves website structure, accessibility, and SEO while building a practical personal portfolio.
